# Virtual Console

Восьмибитный виртуальный компьютер, написанный с нуля на C++: свой
процессор, свой ассемблер, небольшой Си-подобный язык, компилирующийся
в этот же ассемблер, и резидентная терминальная "операционка", в
которую можно вводить команды - с цветным текстовым режимом,
растровой графикой со спрайтами/тайлами, простым 3D-ускорителем,
проигрывателем трекерной музыки и двухпанельным файловым менеджером.
Никакая существующая архитектура процессора не эмулируется - система
команд, карта памяти и все устройства на шине придуманы для этого
проекта.

## Что внутри

- **Свой 8-битный процессор** - собственная система команд,
  интерпретируется в [`CPU.cpp`](VirtualConsole/CPU.cpp).
- **Свой ассемблер** ([`Assembler.cpp`](VirtualConsole/Assembler.cpp))
  - метки, релокация адресов.
- **Мини-C** - намеренно урезанный Си-подобный язык, компилируется
  прямо в тот же ассемблер ([`Compiler.cpp`](VirtualConsole/Compiler.cpp)).
- **Резидентная "операционная система"**
  ([`SHELL.ASM`](VirtualConsole/C/SHELL.ASM)) - интерактивный
  терминал с DOS-подобными командами (`cd`, `dir`, `type`, `copy`,
  `build`, `exec` и т.д.) и вложенным запуском программ (программа
  может запустить другую программу и получить управление обратно,
  когда та завершится).
- **Два виртуальных диска** - обычные папки на компьютере (`C/`,
  `D/`).
- **Текстовый режим** - 80x25, 16 цветов, кодировка CP866/
  псевдографика - плюс отдельный **растровый режим 320x240** со
  спрайтами и тайлами ([`VideoCard.cpp`](VirtualConsole/VideoCard.cpp)).
- **Простой 3D-ускоритель** - вершины/треугольники
  ([`Gpu3D.cpp`](VirtualConsole/Gpu3D.cpp)).
- **Звук** - проигрыватель трекерной музыки формата ProTracker `.mod`
  ([`ModLoader.cpp`](VirtualConsole/ModLoader.cpp) /
  [`SoundCard.cpp`](VirtualConsole/SoundCard.cpp)).
- **Готовые программы**: змейка, демка с вращающимся 3D-кубом,
  тайловая скролл-демка, музыкальный плеер и двухпанельный файловый
  менеджер в стиле Norton Commander
  ([`FM.MC`](VirtualConsole/C/TOOLS/FM.MC)), умеющий запускать другие
  программы по Enter.

## Быстрый старт

**Требования**: Windows (хост напрямую использует `<windows.h>`,
`_getch()` и консольные API - см. [`main.cpp`](VirtualConsole/main.cpp)),
Visual Studio с компонентом "Разработка классических приложений C++".

**Сборка**: открыть [`VirtualConsole.slnx`](VirtualConsole.slnx) в
Visual Studio и собрать конфигурацию `x64` (то же самое делает
[`.vscode/tasks.json`](.vscode/tasks.json) через MSBuild, если удобнее
собирать из командной строки/VS Code).

**Запуск**: запустить `VirtualConsole.exe` **из папки `VirtualConsole/`**
- рядом с ним должны лежать `boot.asm` и папки дисков `C/`/`D/`.

После загрузки терминала можно попробовать:

    dir
    cd demos
    build snake.mc
    snake

...или просто набрать `fm`, чтобы открыть файловый менеджер.

## Структура репозитория

- `VirtualConsole/*.cpp`/`*.h` - хост-эмулятор: процессор, шина, все
  устройства, ассемблер, компилятор Мини-C.
- `VirtualConsole/boot.asm` - минимальный загрузчик.
- `VirtualConsole/C/` - "диск C": `SHELL.ASM`, а также `DEMOS/`,
  `GAMES/`, `TOOLS/`, `DEV/SRC/` (исходники демок/инструментов).
- `VirtualConsole/D/` - "диск D": пустой рабочий диск.
- [`VirtualConsole/ASSEMBLY.ru.md`](VirtualConsole/ASSEMBLY.ru.md) - полная
  техническая документация.

## Документация

[`ASSEMBLY.ru.md`](VirtualConsole/ASSEMBLY.ru.md) - полный технический
