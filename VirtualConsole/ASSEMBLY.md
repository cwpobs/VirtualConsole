# Virtual Console Assembly Language

Документация ассемблера виртуального процессора.

Документ будет дополняться по мере развития виртуальной машины.

---

# 1. Общая информация

Виртуальный процессор использует 8-битные регистры и
16-битное адресное пространство.

Размер памяти:

    65536 байт (64 KB)

Адреса:

    0x0000 - 0xFFFF


---

# 2. Регистры

Процессор имеет четыре основных 8-битных регистра:

    A
    B
    C
    D

Также существуют специальные регистры:

    PC      Program Counter
    SP      Stack Pointer
    FLAGS   Flags Register


## A, B, C, D

Универсальные 8-битные регистры.

Диапазон:

    0 - 255

Пример:

    LDI A, 100
    LDI B, 20


## PC

Program Counter.

16-битный адрес следующей выполняемой инструкции.

После обычного выполнения инструкции PC
автоматически увеличивается.

Инструкции перехода могут изменить PC.


## SP

Stack Pointer.

Указывает на следующий свободный байт стека.

Стек растёт вниз (от старших адресов к младшим) и
занимает верхнюю часть RAM, сразу под MMIO-устройствами.

Текущая начальная позиция:

    0xEFFF

`PUSH register`:

    Записать register по адресу SP, затем SP--

`POP register`:

    SP++, затем прочитать register по адресу SP


## FLAGS

Регистр флагов.

Текущие флаги:

    Bit 0 - ZERO

ZERO устанавливается, если результат сравнения
указывает на равенство.


---

# 3. Инструкции

## LDI

Load Immediate.

Загрузить непосредственное значение в регистр.

Синтаксис:

    LDI register, value

Примеры:

    LDI A, 10
    LDI B, 255
    LDI C, 0xFF

Машинный формат:

    01 register value

Коды регистров:

    A = 0
    B = 1
    C = 2
    D = 3

Пример:

    LDI A, 10

Машинный код:

    01 00 0A


---

## LDA

Load A.

Загрузить значение из памяти в регистр A.

Синтаксис:

    LDA address

Пример:

    LDA 1000

или:

    LDA 0x03E8

Машинный формат:

    02 low high

Адрес является 16-битным.


---

## STA

Store A.

Записать содержимое регистра A в память.

Синтаксис:

    STA address

Пример:

    STA 1000

Машинный формат:

    03 low high


---

## ADD

Прибавить значение регистра к A.

Синтаксис:

    ADD register

Примеры:

    ADD B
    ADD C

Эквивалент:

    A = A + register

Машинный формат:

    04 register


---

## SUB

Вычесть значение регистра из A.

Синтаксис:

    SUB register

Примеры:

    SUB B
    SUB C

Эквивалент:

    A = A - register

Машинный формат:

    05 register


---

## CMP

Сравнить A с другим регистром.

Синтаксис:

    CMP register

Пример:

    CMP B

Если:

    A == B

устанавливается флаг ZERO.

Если:

    A != B

флаг ZERO сбрасывается.

Машинный формат:

    06 register


---

## JMP

Безусловный переход.

Синтаксис:

    JMP address

Пример:

    JMP 100

Можно использовать метку:

    JMP loop

Машинный формат:

    07 low high


---

## JZ

Jump if Zero.

Переход, если установлен флаг ZERO.

Синтаксис:

    JZ address

Пример:

    CMP B
    JZ equal


---

## JNZ

Jump if Not Zero.

Переход, если флаг ZERO не установлен.

Синтаксис:

    JNZ address

Пример:

    CMP B
    JNZ not_equal


---

## PUSH

Положить значение регистра на стек.

Синтаксис:

    PUSH register

Примеры:

    PUSH A
    PUSH B

Машинный формат:

    0A register


---

## POP

Снять значение со стека в регистр.

Синтаксис:

    POP register

Примеры:

    POP A
    POP B

Машинный формат:

    0B register

Пример сохранения и восстановления A:

    PUSH A
    LDI A, 0
    POP A   ; A снова равен исходному значению


---

## HLT

Остановить процессор.

Синтаксис:

    HLT

Машинный код:

    FF


---

# 4. Метки

Метки позволяют обращаться к адресам программы
по имени.

Синтаксис:

    label:

Пример:

    loop:
        JMP loop


Метки можно использовать в инструкциях перехода:

    JMP loop
    JZ success
    JNZ loop


Пример:

    LDI A, 10

loop:

    SUB B
    CMP C

    JNZ loop

    HLT


Ассемблер автоматически заменяет имя метки
на соответствующий адрес.


---

# 5. Комментарии

Комментарии начинаются с символа:

    ;

Пример:

    LDI A, 10 ; Загружаем 10 в A

Всё после `;` до конца строки игнорируется.


---

# 6. Числа

Поддерживаются десятичные числа:

    10
    42
    255

И шестнадцатеричные:

    0x10
    0x2A
    0xFF


---

# 7. Пример программы

Пример простой программы:

    LDI A, 10
    LDI B, 20

    ADD B

    LDI C, 30

    CMP C
    JZ success

    HLT


success:

    LDI D, 123

    HLT


Результат:

    A = 30
    B = 20
    C = 30
    D = 123

# 8. Таблица инструкций

| Opcode | Instruction | Arguments | Description |
|--------|-------------|-----------|-------------|
| 01 | LDI | register, value | Load immediate |
| 02 | LDA | address | Load A from memory |
| 03 | STA | address | Store A to memory |
| 04 | ADD | register | Add register to A |
| 05 | SUB | register | Subtract register from A |
| 06 | CMP | register | Compare A with register |
| 07 | JMP | address | Unconditional jump |
| 08 | JZ | address | Jump if ZERO |
| 09 | JNZ | address | Jump if NOT ZERO |
| 0A | PUSH | register | Push register to stack |
| 0B | POP | register | Pop register from stack |
| FF | HLT | — | Halt CPU |

# 9. Устройства на шине (Memory-Mapped I/O)

Помимо оперативной памяти, к процессору через шину (Bus)
могут быть подключены другие устройства. Каждое устройство
занимает свой диапазон адресов.

Текущая карта адресного пространства:

| Диапазон адресов | Устройство |
|-------------------|------------|
| 0x0000 - 0xEFFF | Memory (RAM) |
| 0xF000 - 0xF001 | Timer |

## Timer

Считает такты. Один такт происходит на каждое
обращение процессора к шине (чтение опкода, операнда
или доступ к памяти/устройству), а не на каждую
инструкцию.

Разные инструкции занимают разное число тактов, в
зависимости от того, сколько байт они читают/пишут:

| Инструкция | Тактов |
|------------|--------|
| LDI | 3 |
| LDA | 4 |
| STA | 4 |
| ADD | 2 |
| SUB | 2 |
| CMP | 2 |
| JMP | 3 |
| JZ | 3 |
| JNZ | 3 |
| HLT | 1 |

| Адрес | Регистр | Чтение | Запись |
|-------|---------|--------|--------|
| 0xF000 | LOW | Младший байт счётчика | Сбрасывает счётчик в 0 |
| 0xF001 | HIGH | Старший байт счётчика | Сбрасывает счётчик в 0 |

Счётчик 16-битный и переполняется циклически
(0xFFFF -> 0x0000).

Пример чтения значения таймера в регистр A:

    LDA 0xF000  ; младший байт таймера в A

Пример сброса таймера:

    STA 0xF000  ; любое значение сбрасывает счётчик

# 10. Зарезервированные возможности

Следующие возможности пока не реализованы,
но предполагаются в будущих версиях процессора:

- CALL
- RET
- Additional flags
- Bit operations
- AND
- OR
- XOR
- NOT
- Shift operations
- Increment / Decrement
- Interrupts
- Video instructions
- Sound instructions
